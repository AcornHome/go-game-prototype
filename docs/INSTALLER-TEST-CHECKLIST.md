# ChinaGo 安装包真机测试清单 v1.0.0

> **测试对象**：`go-game-prototype/installer/ChinaGoSetup-1.0.0.exe` (100 MB)
> **测试环境**：Windows 10 / 11，**未装过任何 KataGo** 的干净机器（或至少清掉 `C:\Tools\KataGo\` 再跑）
> **目的**：验证从「双击安装包」到「打一局完整人机对弈」的端到端体验

---

## 一、安装阶段（5 分钟）

### 步骤 1：双击安装包
- [ ] 双击 `ChinaGoSetup-1.0.0.exe`，**未弹「Windows 已保护你的电脑」SmartScreen 警告**
  - **如果弹了**：点「更多信息」→「仍要运行」（这是 Inno Setup 未签名安装包正常情况，上架 Steam 前需要 EV 代码签名证书，目前先用这个方式跑通）
- [ ] 出现中文安装向导「中国围棋 安装程序」

### 步骤 2：阅读许可协议
- [ ] 默认勾选「我同意许可协议」
- [ ] 看到协议里有 **KataGo MIT 许可证 + KataGo 神经网络权重 MIT 许可证 + 第三方声明**

### 步骤 3：选择安装路径
- [ ] 默认路径 `C:\Program Files\ChinaGo\`（建议**别改**）
- [ ] 自定义路径测试（可选）：改成 `D:\ChinaGo\`，验证能装上去且能启动

### 步骤 4：附加任务
- [ ] 「创建桌面快捷方式」**默认勾选** → 桌面会出现「中国围棋」围棋主题图标（256x256 木纹棋盘 + 三子）
- [ ] 「创建开始菜单快捷方式」**默认勾选**

### 步骤 5：.NET 检查
- [ ] 如果机器装了 .NET 10 Desktop Runtime：直接安装 → 走完
- [ ] 如果**没装 .NET 10**：会弹「是否打开官方下载页面？」→ 选「是」→ 装 .NET 10 Desktop Runtime → 重跑安装包
- [ ] 如果明明已经装了 .NET 10 但安装包仍弹下载提示 → 这是旧版安装包检测 bug，换用 `ChinaGoSetup-1.0.0.exe` 新版

### 步骤 6：完成安装
- [ ] 勾选「运行 中国围棋」→ 点「完成」→ 主窗口弹出

---

## 二、首次启动（关键 5 分钟）

### 步骤 7：KataGo 自适应定位
- [ ] 程序窗口正常出现（不报错）
- [ ] 棋盘 19×19 默认显示
- [ ] 顶栏显示「引擎：未连接」或类似状态
- [ ] **关键验证**：看底栏或日志区有没有出现下面这些日志之一：
  - `KataGo 已定位: <路径>\KataGo\` ← 命中预期路径（程序目录下 KataGo）
  - `KataGo 未找到，请安装 KataGo 或设置 KATAGO_HOME 环境变量` ← **说明 KataGoLocator 4 级全失败**
- [ ] **如果走 C:\Tools\KataGo 回退路径**：说明程序目录下 KataGo 没被发现，是正常回退

### 步骤 8：查看 KataGo 启动日志
- [ ] 顶栏「引擎」点击 → 弹出 KataGo 日志窗口
- [ ] 日志应包含：`Loaded network kata1-b18c384nbt...`
- [ ] 日志应包含：`GTP ready, beginning main protocol loop`
- [ ] **如果看到 `ERROR: Could not find any neural net weights`** → KataGoLocator 路径正确但 weights 缺失，重新跑 deploy.py

---

## 三、对弈功能验证（10 分钟）

### 步骤 9：下第一手棋
- [ ] 棋盘上点击星位（如天元 O10 或 星位 D16）
- [ ] 黑子落在点击位置，轮到白方（AI）
- [ ] **3 秒内** 胜率条 + 候选点开始刷新
- [ ] AI 走出第一手（KataGo 大约 5-15 秒走子）

### 步骤 10：完整一局前 10 手
- [ ] 黑方（你）每落一子，胜率实时更新
- [ ] AI 思考进度条 / 访问数 (visits) 正常滚动
- [ ] 顶栏显示当前手数（如「第 5 手」）
- [ ] 棋盘上能正确显示最后落子标记（小红点）

### 步骤 11：打谱复盘（SGF 导入/导出）
- [ ] 点击「🎲 打谱」（顶栏）→ 弹出打谱窗口
- [ ] 加载一个 .sgf 文件（可以从网上下载一个 9 路的对局 SGF）
- [ ] SGF 正确解析，棋谱能一步步前进 / 后退
- [ ] 关闭窗口后回到主界面

### 步骤 12：死活题
- [ ] 点击「🧩 死活」（顶栏）→ 弹出死活题窗口
- [ ] 选择一个预置死活题 → 开始做题
- [ ] 正确 / 错误提示正常

### 步骤 13：终局数子
- [ ] 主窗口点「📊 终局数子」→ 弹出数子窗口
- [ ] 点几个交叉点 → 显示黑白目数对比

### 步骤 14：联机对战（可选，需要第二台机器）
- [ ] 主机端点「🌐 联机」→ 显示「等待连接 IP」
- [ ] 客户端输入主机 IP → 连接成功 → 能看到对方落子

---

## 四、安装包合规性验证（5 分钟）

### 步骤 15：检查安装目录结构
打开 `C:\Program Files\ChinaGo\`（或你自定义的路径）：
- [ ] `GoGame.exe` 主程序
- [ ] `KataGo\` 子目录存在
- [ ] `KataGo\katago.exe` 存在
- [ ] `KataGo\weights\kata1-b18c384nbt.bin.gz` 存在（约 94 MB）
- [ ] `KataGo\default_gtp.cfg` 存在
- [ ] `KataGo\License.txt`（MIT 引擎许可证）
- [ ] `KataGo\weights\License.txt`（MIT 权重许可证）
- [ ] `THIRD-PARTY-NOTICES.txt`（第三方组件声明）

### 步骤 16：卸载测试
- [ ] 控制面板 → 程序 → 卸载 ChinaGo
- [ ] 卸载完成，检查 `C:\Program Files\ChinaGo\` 已被清空
- [ ] 桌面图标被移除
