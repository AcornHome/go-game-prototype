# Screenshot Capture Script — ChinaGo for itch.io

> itch.io / Steam 推荐 **5–8 张 1920×1080 PNG/JPG**，覆盖核心场景。
> Windows 一台电脑即可，不需要任何付费软件。

---

## 0 · 准备（5 分钟）

| 项 | 怎么做 |
|---|---|
| 屏幕分辨率 | 设置 → 显示 → 1920×1080（首选），或最低 1280×720 也能用 |
| 缩放 | **100%**（缩放 125%+ 会让字边缘锯齿） |
| 显卡驱动 | 关掉 NVIDIA / AMD 驱动覆盖（防止 OSD 角标入镜） |
| 通知 | Win10 设置 → 通知 → 全关（防止截图里出现 QQ 弹窗） |
| 高 DPI 截图 | 设置 → 显示 → 高 DPI 设置 → 「用我登录的 Windows 缩放」（不要强制缩放） |
| 截图工具 | **Win + Shift + S**（自带，最稳）；或 `Win + PrintScreen`（整屏到截图文件夹） |

> 不要用 Snipping Tool 截屏后再用 PrtScn —— 会留下工具悬停高亮。

## 1 · 主对弈（中盘，重点戏，⭐ 必须）

**期望效果**：19 路棋盘中盘，10+ 个黑白子布局，看出"这是一局真在下的棋"。

### 步骤
1. 启动 ChinaGo
2. 主界面 → 19 路 → 黑先 / 白先 / AI 推荐 → 开始
3. 走 8–12 手黑白交替，让局面看起来 **有攻防**（贴一个角 + 一个边 + 几个散子）
4. **AI 思考时（等胜率跳动的瞬间）** 截图 → `01-main-gameplay.png`

### 验收
- [ ] 棋盘可见，局面「看着是真在打」
- [ ] 右上角玩家信息栏清晰
- [ ] 顶栏「📬 反馈」「ℹ️ 关于」按钮可见（不是简洁到空）
- [ ] 底栏**教程 + 终局数子**按钮可见（设计有意识）

## 2 · AI 思考胜负率（⭐⭐ 必杀图）

**期望效果**：右侧实时胜负率面板在动，让玩家一眼看出"这软件有 AI"。

### 步骤
1. 接场景 1 的对弈
2. 让 AI 走一步 → 等 KataGo 推算中（**右下面板数字在跳**）
3. **截屏**：让「🤖 AI 在思考…」动效可见（不要等它走完）
4. 截图 → `02-ai-thinking.png`

### 验收
- [ ] 胜负率柱状图 / 数字可见
- [ ] "AI 在思考"或类似动效可见
- [ ] 候选推荐（如果 UI 有）可见

## 3 · AI 复盘报告（⭐ 加分项）

**期望效果**：对弈后点「AI 复盘」→ 弹出 HTML 报告（漂亮木纹风）。

### 步骤
1. 完成一局或主动认输（顶栏某按钮）
2. 点「AI 复盘」 → 选择 K 线分析 → 等 5–10 秒出报告
3. 在系统默认浏览器里**全屏展开**报告（F11）
4. 截图 → `03-ai-review-report.png`

### 验收
- [ ] 报告木纹风格可见（暖色背景）
- [ ] 「胜负率走势」「致命失误」「KataGo 建议」等区块有内容
- [ ] 整张截图里有**真实数据**（不要 demo 占位符）

> 备选：如果 V1.0 复盘还在跑第三方云，改成截图 SGF 列表页或 SGF 复盘页。

## 4 · 打谱复盘 / SGF

**期望效果**：载入一个 SGF 文件，能 step 前进/后退。

### 步骤
1. 顶栏「🎲 打谱」（V1.x 入口）→ 弹出文件选择 → 选一个有 50+ 手的 SGF
2. **把棋盘走到第 20 手**（点 ▶前进 或鼠标拖动走子记录）
3. 让 AI 对当前局面跑分析
4. 截图 → `04-sgf-replay.png`

### 验收
- [ ] SGF 走子记录侧栏可见
- [ ] 当前手数标记可见
- [ ] 棋盘上是中盘局面（不是开局空盘）

> 若 SGF 复盘功能 V1.0 还没做，**改截**：打谱入口弹窗 / 选择 SGF 的对话框。
