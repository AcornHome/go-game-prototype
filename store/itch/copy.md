### Long description (paste into "Description" field)

```
A no-paywall desktop trainer for Chinese Go (Weiqi / 围棋), the oldest board
game still played competitively today. ChinaGo pairs a clean, distraction-free
interface with the open-source KataGo neural-network engine so you can study,
drill, and play against world-class AI entirely on your own machine.

WHY CHINAGO?
----------------
Most Go trainers lock the strongest engine behind a subscription. ChinaGo
bundles a real KataGo checkpoint with the installer — no accounts, no
subscriptions, no online requirement. You pay what you want, you keep the
download forever, the engine runs on your laptop.

BUILT FOR LEARNING
------------------
- Real-time winrate / score-lead readouts while you think
- One-click undo + SGF export so every game is a study opportunity
- Replay any SGF (open-source library) and step through moves
- Daily life-and-death (tesuji) problems with hint mode
- Built-in tutorial that explains the rules through interactive play
- Smart end-of-game scoring — no need to manually mark dead stones

KEY FEATURES
----------------
✓ Powered by KataGo (MIT-licensed neural net; weights released under Apache 2.0)
✓ Board sizes 9 / 13 / 19, plus custom handicap placement
✓ Real-time analysis: visits, winrate, score lead, top candidate moves
✓ SGF import / export (compatible with Sabaki, Go Magic, KGS, OGS)
✓ Offline play — your games never leave the computer
✓ Optional AI review report (HTML, beautiful and self-contained)
✓ Adjustable thinking time and KataGo strength

PERFECT FOR
----------------
- Beginners learning Go who want a friendly board with strong feedback
- Club players (SDK / dan) sharpening their reading against a tough sparring partner
- Teachers looking for an offline classroom tool with replay + scoring
- Researchers who want a clean GUI on top of KataGo's GTP interface

OPEN-SOURCE CREDITS
----------------
This project stands on the shoulders of giants:
- KataGo (David J. Wu, MIT) — the engine that actually plays
- Sabaki (GPL) — GUI design inspiration
- All SGF libraries used (FF[4] format)
Full attributions and licenses: bundled as `THIRD-PARTY-NOTICES.txt` in the
install directory.

Q: Does it work on Mac / Linux?
A: Currently Windows (64-bit) only. Mac build is on the roadmap.

Q: How strong is the AI?
A: With the bundled checkpoint, comfortably stronger than human top professional
   players with reasonable thinking time. Strength scales with thinking time.

Q: Is my data sent anywhere?
A: No. There is no telemetry, no analytics, no cloud sync. Everything stays on
   your machine.

Q: Can I use my own KataGo weights?
A: Yes — point the engine picker at any `.bin.gz` neural-net file.

Q: Can I get a refund if it doesn't work for me?
A: itch.io's standard refund policy applies.
```
